# Instruções de Execução - QA Engineer Test (Joel Rocha)

## Sobre o Projeto
Este repositório contém os testes automatizados para validar o fluxo de Login do sistema Navega.

## Como Executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/joelrocha68/qa-engineer-test.git

2. Instale as dependências:
   ```bash
   npm install
    ```
3. Vá para a pasta Automation:
   ```bash
   cd Automation
    ```
4. Execute os testes no modo interativo:
    ```bash
   npx cypress open
    ```
5. Execute os testes em modo headless:
   ```bash
   npx cypress run
    ```
